Apri la guida

Com’è fatta questa cartella

Pagine

  • index.html è questa pagina.
  • Una pagina per tavola di sistema e una per banco TEST.
  • Ogni pagina contiene il suo template in un tag <template>.

Script

  • assets/dc-lite.js legge i template: segnaposto, condizioni, liste, eventi.
  • assets/calamaio-test.js è il simulatore: disegno degli schermi, menu, gesti, refresh e-ink.

Senza internet

  • I font sono in assets/fonts, con le loro licenze.
  • Nessun server: basta il doppio clic su index.html.
  • Funziona in Chrome, Edge, Firefox e Safari recenti.
